# La Cochera — local concept

A custom Spanish-language automotive landing page, built with vanilla JavaScript, CSS and Vite. No backend, booking submission, fabricated ratings or assumed business address.

## Commands

- `npm install`
- `npm run dev -- --port 5173` — local preview at http://127.0.0.1:5173
- `npm run build`
- `npm run preview`

## Motion and interactions

Photo-derived hero video, CSS atmospheric light, scroll-linked photo transform, looping textual brand marquee, treatment filters and native accessible detail dialogs, keyboard-controlled image carousel, mobile navigation and native FAQ accordions. The motion toggle, reduced-motion preference, visibility state and intersection state govern decorative playback. No scroll hijacking.

## Media and release status

`public/media` is managed separately and contains conceptual media plus any source-verified client assets. Concept imagery is explicitly labeled and is not evidence of client work. Brand names imply no partnership. Email and Instagram are direct outbound contacts; there is no fake booking form. Verify service availability, legal details, location, approved brand assets and media authorization before a production release. No deployment has been performed.
